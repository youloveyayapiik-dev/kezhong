# 课钟

安卓课表。算起床时间，按周看课，标出节假日，并写入系统闹钟和日历。

安装包不包含任何人的个人课表。课表只存在自己的手机里。

## 能做什么

- 今天先看到下一节课的时间和教室，再往下是后面的课
- 按周切换，周次直接点
- 导入 xls、xlsx、csv，支持正方这类「课程 / 周次 / 地点 / 教师」写法，以及单双周
- 导入后提示时间冲突、整周没课、同一门课不止一间教室
- 用洗漱、路程、容错算出起床时间，写入系统闹钟
- 一键把还没上的课写入系统日历，并带上课前提醒
- 国务院 2026 年节假日：中秋、国庆，以及已公布的调休上班。2027 年元旦只标 1 月 1 日

## 自己编译

需要 JDK 11、Android SDK（platforms API 34 和 build-tools），以及 `keytool`。

```bash
export ANDROID_HOME="$HOME/Android/Sdk"
chmod +x build.sh
./build.sh
```

签名只用本地生成的 `debug.keystore`，这个文件不会提交。装过旧版课钟的手机如果签名不同，先卸载再装。

`libs/jxl-2.6.12.jar` 是 JExcelApi，用来读 xls，许可证是 LGPL。
